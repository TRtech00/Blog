## Kullanıcıya yakınlaştırmak

Coğrafi olarak dağıtılmış edge node'ları sayesinde statik ve yarı dinamik içerikleri kullanıcıya birkaç milisaniyede ulaştırmak mümkün. Next.js 15 ile `app` yönlendirici, ISR ve Route Handlers birlikte çalışıyor.

### Önbellek katmanları

1. **CDN**: Görseller ve statik varlıklar için.
2. **Edge cache**: HTML parçalarını saklar.
3. **Origin**: Veritabanı veya API çağrıları.

## Revalidate stratejisi

ISR ile saniyeler seviyesinde `revalidate` belirleyerek hem güncellik hem hız sağlanabilir.

```ts
export const revalidate = 60;
```

### Ölçüm

- Core Web Vitals için `Next.js Analytics` veya `Web Vitals` paketi kullanın.
- Time To First Byte (TTFB) değerlerini edge bölgelere göre kıyaslayın.
