## Kontrast kuralları

AA ve AAA kontrast değerlerini sağlayan paletler oluşturun. Arka plan katmanları için opaklıkla oynayarak derinlik hissi yaratabilirsiniz.

### Ton eşleştirme

Işık ve gölge dengesi için `backdrop-filter` ve yumuşak gölgeler kullanın. Temalar arasında geçiş yaparken `prefers-reduced-motion` tercihine saygı duyun.

```css
@media (prefers-reduced-motion: reduce) {
  * {
    transition: none !important;
    animation-duration: 0.01ms !important;
  }
}
```

## Parlaklık tuzakları

- Saf beyaz metin kullanmayın, %90-92 parlaklık daha iyi.
- Doygun neon tonları yerine pastel vurgular seçin.
- Kenar belirginliğini artırmak için ince konturlar.
